Instructional Lab Guide for L1 Curriculum 
All participants of L1 Course are requested to ensure that the following 
System configuration and Software are available.  
It is fully based on tech stack (Java / Dotnet / Python)  a candidate or Team 
is going to work with the use case.  
Tech-Agnostic Full-Stack Development Using GenAI 
1. Hardware / System Requirements 
Minimum (Individual Developer Machine) 
• CPU: Quad-core (Intel i5/AMD Ryzen 5 or above) 
• RAM: 16 GB 
• Storage: 512 GB SSD 
• GPU: Not required for basic development, but useful if running local inference 
• OS Support:  
o Windows 11 
o macOS 12+ 
o Linux (Ubuntu 22.04 LTS recommended)
